# Select Reduced Federated Memory Organ R1

- Decision ID: AOA-CENTER-D-0038

## Context

The active-organ program tested no-memory, reviewed pull-only, monolithic,
selective federated, always-shadow, and isolated agent-local forms. The
contract spine, explicit-pull path, outcome receipts, typed mechanical
lifecycle, distributed erasure, and agent-local isolation passed bounded
source-local laboratories. Selective shadow and canary results were promising,
but reviewed natural OS outcomes, cross-model coverage, operator-load
reduction, and real 7/30-day wall-clock evidence remain incomplete.

The ecosystem needs one decision that preserves the long-horizon architecture
without treating every implemented research contour as admitted behavior.

## Options considered

1. Land the full selective proactive C architecture as the default organ.
2. Keep only verified-current/no-memory and discard the memory work.
3. Select a reduced federated organ whose admitted core is reviewed public
   pull-only A, while D and selective C remain disabled, separately gated
   growth contours.
4. Select the monolithic B or always-shadow form for simplicity.

## Decision

Choose option 3.

The first admissible OS Abyss memory form is Reduced Federated Two-Speed Organ
R1:

- `aoa-memo` reviewed public meaning and lifecycle;
- `.aoa` raw/session evidence as candidate provenance only;
- `aoa-sdk` recall intent, route resolution, and `RunPlan`;
- `abyss-stack` exact read-only delivery and runtime lifecycle;
- `abyss-machine` mandatory host/resource/storage/model admission;
- rebuildable `aoa-kag` projections below canonical authority;
- `aoa-evals` bounded proof and `aoa-stats` descriptive measurement;
- `aoa-agents` identity and agent-local namespace rights;
- the sole operator as final semantic, policy, private, erase, model, and
  irreversible authority.

R1 admits only the explicit-pull A core over public-reviewed memory and current
owner refs. D remains consumer-zero until private storage, natural utility,
and namespace erasure are separately admitted. Selective C remains a disabled
shadow/canary research envelope until natural outcomes, operator cost,
cross-model or model-specific policy, and real 30-day evidence pass. B,
always-shadow, automatic sharing, live private memory, and training remain
excluded.

The source landing may retain disabled C/D contracts only when the final audit
proves no live trigger, default consumer, private reader/writer, self-promotion,
or effect route.

## Rationale

This form keeps the architecture capable of growth while making present
authority equal to present evidence. A passed the bounded read-only owner
path and rollback gates. D demonstrated the smallest safe local-learning
boundary. Selective C demonstrated a useful mechanism but not natural
production benefit. B and always-shadow crossed explicit safety or cost
falsifiers.

Choosing R1 prevents incomplete evidence from becoming an implicit proactive
feature and prevents a later agent from mistaking source-local contracts for
live admission.

## Consequences

- The consolidated landing must be reviewed against R1, not against the
  largest implemented research contour.
- Paired owner decisions define only local responsibilities and may not absorb
  sibling authority.
- Public/source contracts may land before live activation, but disabled
  contours must remain visibly consumer-zero.
- Real 7/30-day, natural operator, and reviewed OS outcome evidence remain
  required before any proactive reopening.
- The tradeoff is deliberate under-utilization of promising C mechanisms
  until stronger evidence exists.
